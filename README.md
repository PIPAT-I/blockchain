# Blockchain Consensus Simulation (จำลองระบบฉันทามติบล็อกเชน)

โปรเจคนี้เป็นการจำลองการทำงานของเครือข่ายบล็อกเชน (Blockchain Network) พร้อมกับระบบฉันทามติ (Consensus Mechanism) ที่ออกแบบเองโดยมีพื้นฐานจาก Proof-of-Stake และเพิ่มแนวคิดของ "Proof-of-Search" เข้าไป เพื่อสาธิตกระบวนการที่โหนดต่างๆ ในเครือข่ายเห็นพ้องต้องกันในการเพิ่มบล็อกใหม่, การตรวจสอบความถูกต้องของข้อมูล, และการแจกจ่ายรางวัล (Reward) 

## ภาพรวมการทำงาน

ระบบฉันทามติของโปรเจคนี้มีชื่อว่า **Proof-of-Search** ซึ่งทำงานร่วมกับ **Proof-of-Stake** โดยมีขั้นตอนดังนี้:

1.  **Search Phase (ช่วงการค้นหา)**: เมื่อมีการร้องขอให้ค้นหาข้อมูล (Vector) ในบล็อกเชน โหนดทั้งหมดจะเริ่ม "ค้นหา" Hash ของข้อมูลนั้น
    *   **Stake**: ความเร็วในการค้นหาของแต่ละโหนดจะขึ้นอยู่กับจำนวนเหรียญ (Token) ที่โหนดนั้นมีอยู่ (Stake) โหนดที่มีเหรียญเยอะกว่าจะ "ทำงาน" หรือค้นหาได้เร็วกว่า
2.  **Winner Announcement (ช่วงประกาศผู้ชนะ)**: โหนดแรกที่ค้นหาข้อมูลเจอจะประกาศตัวเองเป็น "ผู้ชนะ" (Winner) และส่งข้อมูลที่ค้นเจอพร้อมเวลาที่ใช้ไปให้โหนดอื่นๆ
3.  **Voting Phase (ช่วงการโหวต)**: เมื่อโหนดอื่นๆ ได้รับประกาศผู้ชนะ จะหยุดการค้นหาของตัวเองและเข้าสู่สถานะ "โหวต" (Voting)
4.  **Tally & Reward (ช่วงรวบรวมผลและแจกรางวัล)**:
    *   ผู้ชนะจะรวบรวมผลโหวตจากโหนดอื่นๆ
    *   หากได้รับเสียงโหวต "YES" คิดเป็น **มากกว่า 50% ของ Stake ทั้งหมดที่เข้าร่วมโหวต** จะถือว่าฉันทามติสำเร็จ
    *   บล็อกใหม่ที่บันทึกผลลัพธ์การค้นหาและรางวัลจะถูกเพิ่มเข้าไปในเชน
    *   **รางวัล**: ผู้ชนะได้รับ 10 เหรียญ, โหนดที่โหวต "YES" ได้รับ 1 เหรียญ

## การติดตั้งและเตรียมความพร้อม (Setup)

### สิ่งที่ต้องมี
- Python 3.10+
- Docker & Docker Compose (แนะนำ)

### ขั้นตอนการติดตั้ง
1.  Clone โปรเจคนี้ลงในเครื่องของคุณ:
    ```bash
    git clone <your-repository-url>
    cd blockchain
    ```
2.  ติดตั้ง Dependencies (หากต้องการรันแบบ Manual):
    ```bash
    pip install -r requirements.txt
    ```

## การรันโปรเจค (Running the Project)

### วิธีที่ 1: รันผ่าน Docker (แนะนำ)
วิธีนี้จะสร้างเครือข่ายจำลองประกอบด้วย 4 โหนด (`node1` ถึง `node4`) ซึ่งเชื่อมต่อกันอัตโนมัติ

1.  Build และ Start container ทั้งหมด:
    ```bash
    docker-compose up --build
    ```
2.  โหนดต่างๆ จะเริ่มทำงานที่ Port `5001`, `5002`, `5003`, และ `5004`

### วิธีที่ 2: รันด้วยตนเอง (Manual)
คุณสามารถรันแต่ละโหนดในหน้าต่าง Terminal ที่แยกจากกันได้

**Terminal 1 (สำหรับ Node 1):**
```bash
python node_server.py --port 5001
```

**Terminal 2 (สำหรับ Node 2 - เชื่อมต่อไปยัง Node 1):**
```bash
python node_server.py --port 5002 --peers http://127.0.0.1:5001
```

**Terminal 3 (สำหรับ Node 3 - เชื่อมต่อไปยัง Node 1):**
```bash
python node_server.py --port 5003 --peers http://127.0.0.1:5001
```

## คำสั่งและการใช้งาน (API Commands)

คุณสามารถโต้ตอบกับโหนดต่างๆ ผ่าน API โดยใช้เครื่องมืออย่าง `curl` หรือ Postman

---


### 1. ดูข้อมูลสถานะของโหนด (Get Node Info)
ดูข้อมูลทั่วไปของโหนด เช่น ชื่อ, Peers, จำนวนเหรียญ (Tokens), และสถานะปัจจุบัน

`GET /info`
```bash
curl http://localhost:5001/info
```

### 2. ดูข้อมูลทั้งหมดในบล็อกเชน (View Blockchain)
ดึงข้อมูลบล็อกทั้งหมดที่มีอยู่ในเชนของโหนดนั้นๆ

`GET /blockchain`
```bash
curl http://localhost:5001/blockchain
```

### 3. เริ่มกระบวนการค้นหาและฉันทามติ (Start Search / Consensus)
คำสั่งนี้เป็นหัวใจหลักของระบบ ใช้เพื่อเริ่มต้นกระบวนการ "Proof-of-Search" โดยส่ง Vector ของข้อมูลที่ต้องการค้นหา

`POST /start-search`
```bash
curl -X POST http://localhost:5001/start-search \
     -H "Content-Type: application/json" \
     -d '{"vector": "[0.99, 0.88, 0.77, 0.66, 0.55]"}'
```
*เมื่อรันคำสั่งนี้ เครือข่ายจะเริ่มค้นหา, แข่งขัน, และโหวตโดยอัตโนมัติ*

---


### 4. การโหวต (Cast Vote)
หลังจากมีผู้ชนะประกาศตัว โหนดอื่นๆ จะเข้าสู่สถานะ `VOTING` คุณสามารถสั่งให้โหนดส่งผลโหวตได้ด้วยคำสั่งนี้

**หมายเหตุ**: โดยปกติขั้นตอนนี้ควรถูกทำโดยอัตโนมัติ แต่ API นี้มีไว้เพื่อให้สามารถทดสอบและควบคุมได้

`POST /cast-vote`
```bash
# โหวต YES (เห็นด้วยกับผู้ชนะ)
curl -X POST http://localhost:5002/cast-vote \
     -H "Content-Type: application/json" \
     -d '{"vote": "YES"}'

# โหวต NO (ไม่เห็นด้วยกับผู้ชนะ)
curl -X POST http://localhost:5003/cast-vote \
     -H "Content-Type: application/json" \
     -d '{"vote": "NO"}'
```
*คุณต้องส่งคำสั่งนี้ไปยังโหนดที่ **ไม่ใช่ผู้ชนะ** และอยู่ในสถานะ `VOTING`*

---


### 5. เพิ่มโหนดเพื่อนบ้าน (Add Peer)
ใช้สำหรับเพิ่มโหนดใหม่เข้ามาในเครือข่ายด้วยตนเอง

`POST /add_peer`
```bash
curl -X POST http://localhost:5001/add_peer \
     -H "Content-Type: application/json" \
     -d '{"peer_address": "http://127.0.0.1:5005"}'
```

## การทดสอบการปลอมแปลงข้อมูล (Tampering Test)
สคริปต์ `test_tampering.py` ถูกสร้างขึ้นเพื่อสาธิตว่าบล็อกเชนสามารถป้องกันการแก้ไขข้อมูลได้อย่างไร

รันสคริปต์:
```bash
python test_tampering.py
```
สคริปต์จะสร้างเชน, ลองแก้ไขข้อมูลในบล็อกเก่า, และแสดงให้เห็นว่าระบบสามารถตรวจจับการเปลี่ยนแปลงนั้นได้ ทำให้เชนไม่สมบูรณ์ (Invalid)
